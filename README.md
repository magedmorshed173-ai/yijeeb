## لماذا يجيب؟

| المعنى | الشرح |
|--------|-------|
| **يردّ** | ردّ فوري على كل رسالة — بلا تأخير ولا تعليق |
| **يجيب** | يجيب لك كل وسائل التواصل في تطبيق واحد |
| **يوصّل** | صوتك وصورتك توصل بجودة واضحة |

تطبيق دردشة **مبني للمستخدم العربي أولاً** — تصميم RTL أصيل، تشفير من طرف إلى طرف، حجم صغير، وتجربة نظيفة بلا إعلانات.

## التشغيل المحلي

```bash
# يتطلب Node.js 22.13+ (لأن node:sqlite مدمج)
export JWT_SECRET=$(node -e "console.log(require('crypto').randomBytes(48).toString('hex'))")
cd server
npm install
npm start
# افتح http://localhost:3000
```

سجّل حسابين (من متصفحين أو نافذتين متخفيتين) وجرّب: محادثة خاصة، مجموعة، رسالة صوتية، مرفق.

## النشر على Render

1. المستودع جاهز — في Render: **New → Blueprint** واختر `yijeeb`
2. Render يقرأ `render.yaml` تلقائيًا (JWT_SECRET يُولَّد تلقائيًا، VAPID مفاتيح الإشعارات تُولَّد أول إقلاع)
3. **مهم**: الخطة المجانية تفقد البيانات عند كل نشر. للإنتاج رقِّ إلى Starter وأضف قرصًا:
   ```yaml
   plan: starter
   disk:
     name: yijeeb-data
     mountPath: /var/data
     sizeGB: 1
   envVars:
     - key: DATA_DIR
       value: /var/data
   ```
4. (اختياري) اربط دومينك المخصص من إعدادات الخدمة

## نقاط حرجة

- **لا تفقد رمز الاستعادة** — بدونه، تغيير الجهاز = فقدان الرسائل
- **الخادم لا يرى المحتوى** — كل الرسائل نصوص مشفرة عنده
- **حذف العضو = تدوير المفتاح** — المُزال لا يقرأ ما بعده
