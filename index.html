المميزات

كل وسائل التواصل… في تطبيق واحد خفيف

ما عاد تحتاج أربع تطبيقات — يجيب يجمعها لك كلها بسرعة عالية وتجربة عربية سلسة.

شات نصي وصوتي

رسائل نصية ورسائل صوتية بضغطة واحدة، مع إشعارات ذكية ما تفوّتك شي.

مكالمات فيديو

فيديو واضح وثابت حتى على الشبكات الضعيفة — اجتماعات وأهل وأصحاب بجودة ممتازة.

خفيف وسريع

حجم التطبيق صغير ومصمم يشتغل بسلاسة حتى على الأجهزة القديمة والشبكات البطيئة.

خصوصيتك أولًا

تشفير للمحادثات ووضع الرسائل المختفية — محادثاتك ملكك وحدك.

عربي أولاً

تصميم RTL أصيل، خطوط عربية واضحة، وواجهة مبنية للمستخدم العربي — ليست ترجمة لاحقة.

بلا إعلانات

لا إزعاج ولا مقاطعة ولا محتوى مدفوع مخفي — تجربة نظيفة من البداية للنهاية.

مبادئنا

ليش تختار يجيب؟

ثلاثة مبادئ نبني عليها كل سطر في التطبيق — لو خالفنا واحدًا، فذكّرونا.

خفيف وسريع

وعد الأداء
  • إقلاع فوري في ثوانٍ
  • سلس حتى على الأجهزة القديمة
  • يشتغل حتى بشبكة ضعيفة

عربي أولًا

هويتنا — لا نفاوض عليها
  • مصمم RTL من الأساس
  • خطوط عربية واضحة ومريحة
  • تجربة كُتبت بالعربية قبل أي لغة

خاص وآمن

وعد الخصوصية
  • تشفير طرف-لطرف لمحادثاتك
  • رسائل مختفية بعد قراءتها
  • بلا إعلانات — إلى الأبد

Docker

صورة واحدة تعمل في أي مكان — بيانات دائمة عبر مجلد /data

git clone https://github.com/magedmorshed173-ai/yijeeb.git && cd yijeeb && docker compose up -d

عند التشغيل المحلي تُخزَّن كل البيانات في مجلد data على جهازك — قاعدة بيانات ومرفقات ومفاتيح، بلا سحابة ولا وسيط.
